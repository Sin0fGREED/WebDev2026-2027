# Hollowmere - Web Development 2026-2027

A web application for Hollowmere, an live action Guild as part of the Web Development course for the 2026-2027 academic year.

## About the project

Hollowmere is a guild that requested us to create a central application to manage its members, equipment, quests, training activities and encounter records. the application is based on the Hollowmere case description and is developed according to the requirements of the course manual.

### Features

The project features an:
- **Armoury:** Manage equipment, tracks loans/returns and record equipment conditions.
- **Quest Board:** Create quests, manage party requests and organize quest participation.
- **Training Yard:** Schedule training sessions, manage attendance and maintain training records.
- **Archive & Bestiary:** Post quest reports, record creatures encounters and maintain an archive of filed reports.
- **Member Management:** supports multiple guild memberships and access to relevant application functionalities.
